# Tag Manager - Obsidian 标签管理工具

## 功能简介

一款用于批量管理 Obsidian 笔记（MD文件）和 TXT 文件标签的工具软件。

## 主要功能

### 1. 批量添加标签
- 通过 JSON 文件导入关键词标签
- 手动添加/删除标签
- 扫描文件夹中所有 MD/TXT 文件
- 根据关键词全文匹配，自动在文件末尾添加对应 tag
- 已存在 tag 的文件不会重复添加

### 2. 批量删除标签
- 根据已有标签列表，批量删除指定 tag
- 精确匹配完整 tag，不会误删包含关系的 tag（如删除 #科技 不会影响 #科技发展）

### 3. 搜索标签
- 从已加载的标签列表中选择进行搜索
- 显示所有包含该 tag 的文件
- 支持同时搜索多个标签

### 4. 扫描已有标签
- 扫描目标文件夹中所有已存在的标签
- 可批量将已有标签添加到当前标签列表
- 方便快速收集现有标签

### 5. 右键操作
- 双击结果列表可打开对应文件
- 右键点击可单独对某个文件添加/删除 tag

## JSON 格式

```json
["经济", "政治", "科技"]
```

## 使用方法

1. 运行 `python tag_manager.py` 或双击 `tag_manager.exe`
2. 选择目标文件夹（默认为软件所在目录）
3. 点击"JSON"按钮导入标签文件，或手动点击"+"添加标签
4. 选择操作：添加Tag / 删除Tag / 搜索
5. 查看结果列表，双击打开文件或右键进行单独操作

## 文件支持

- `.md` 文件（Obsidian 笔记）
- `.txt` 文件

## 系统要求

- Python 3.7+ (运行源码)
- Windows 系统 (编译版)

## 编译命令

```bash
pip install pyinstaller
pyinstaller --onefile --noconsole tag_manager.py
```
